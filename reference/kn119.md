# Digitized survival data from KEYNOTE-119

Digitized survival data from KEYNOTE-119

## Usage

``` r
data(kn119)
```

## Format

A data frame with five variables:

- time:

  Numeric; survival time (months).

- event:

  Numeric; 1=event, 0=censored.

- arm:

  Factor/character; treatment arm.

- id:

  Factor/character; patient id.

- study:

  Character; study label.
