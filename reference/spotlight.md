# Data from the spotlight Trial

A dataset containing digitized survival data from a clinical trial.

## Usage

``` r
spotlight
```

## Format

A data frame with four variables

- time:

  A numeric vector representing the survival time.

- event:

  A numeric vector indicating the event status (1 = event, 0 =
  censored).

- id:

  Patient id

- arm:

  A factor or character vector for the treatment arm.

## Source

<https://clinicaltrials.gov/ct2/show/NCT03504397>
