# Toxicity and QoL data from Keynote062_toxicity

Toxicity and QoL data from Keynote062_toxicity

## Usage

``` r
data(Keynote062_toxicity)
```

## Format

A data frame with 8 variables

- EventName:

  Adverse event name.

- SystemOrganClass:

  System organ class.

- Incidence_G1_4_Control:

  Incidence (%) any-grade in control.

- Incidence_G1_4_Experimental:

  Incidence (%) any-grade in experimental.

- Incidence_G3_4_Control:

  Incidence (%) grade 3–4 in control.

- Incidence_G3_4_Experimental:

  Incidence (%) grade 3–4 in experimental.

- qol:

  Numeric QoL score.

- N_patients:

  Named numeric vector with n per arm.
