# Calculate the Time Ratio

Extracts the Time Ratio (or Acceleration Factor) for the survival
component of the cure model and its 95

## Usage

``` r
time_ratio(model)
```

## Arguments

- model:

  An object of class 'bcm_fit' returned by \`fit_bayesian_cure_model\`.

## Value

A named list containing the estimated \`time_ratio\` (posterior median),
its 95
