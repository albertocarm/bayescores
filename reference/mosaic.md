# IPD data from the MOSAIC trial

IPD data from the MOSAIC trial

## Usage

``` r
data(mosaic)
```

## Format

A data frame with 4 variables

- time:

  Numerical time to event or censoring.

- status:

  Event indicator (1 = event, 0 = censored).

- curve:

  Numeric identifier for the survival curve.

- arm:

  Character string indicating the treatment arm.
